1. Overview

Genrolla is a fast, SEO-friendly blog theme designed for content creators. It features a semi-dark design with a neon green accent, a one-click demo importer, built-in SEO (schema markup, breadcrumbs, table of contents), a trending section, and full responsiveness.

Key Features

  • One-click demo import — 12 sample posts, 6 categories, 20 tags, featured images & comments
  • SEO-ready — JSON-LD Article + BreadcrumbList schema, auto Table of Contents, author box
  • Trending section — most-commented posts, falls back to the Highlight category
  • Card image fallback — gradient + icon when a post has no featured image
  • Customizer — colors, hero, newsletter, footer
  • Responsive — mobile, tablet, desktop
  • Translation ready — .pot file included
  • RTL ready — rtl.css included

2. Installation

Option A — Via WordPress Admin (recommended)

  1. Download the theme ZIP file.
  2. Go to Appearance -> Themes -> Add New.
  3. Click Upload Theme and select the ZIP file.
  4. Click Install Now, then Activate.

Option B — Via FTP

  1. Upload the genrolla folder to wp-content/themes/.
  2. Go to Appearance -> Themes and activate Genrolla.
Make sure Settings -> Reading -> "Your homepage displays" is set to "Your latest posts" so the front page template is used.

3. First-Time Setup

  1. Import demo content — go to Appearance -> Import Demo and click Import Demo Content Now. This creates 12 sample posts, categories, tags, featured images and comments.
  2. Customize — go to Appearance -> Customize and set your logo, colors, hero title/subtitle and newsletter text.
  3. Menus — go to Appearance -> Menus and create a Primary menu.
  4. Widgets (optional) — go to Appearance -> Widgets and add content to the Sidebar and Footer columns.
  5. Pages — create an About page and select the About template in the editor sidebar.

5. Menus

The theme registers two menu locations:

  • Primary Menu — top navigation
  • Footer Menu — footer links (optional)

Go to Appearance -> Menus, create a menu, add items, and assign it to the Primary location.

6. Widgets

Registered widget areas:

  • Sidebar — shown on single posts & archives
  • Footer Column 1–3 — footer widgets

Add widgets from Appearance -> Widgets. For the sidebar we recommend: Latest Posts, Categories, Tag Cloud.

7. Trending Section

The home page "Trending now" section uses this priority:

  1. Most-commented posts (real engagement)
  2. Highlight category — if no posts have comments
  3. Latest posts — if Highlight is empty

To control the fallback: create a category named Highlight (slug highlight) and assign your featured posts to it.

8. Newsletter

The theme includes a newsletter form that saves emails directly to WordPress — no plugin required:

  • Emails are stored in a Subscribers post type (visible in the admin menu)
  • On the Subscribers list page, click Export CSV to download all emails
  • Duplicate emails are rejected automatically; success/error messages show inline

Connect an Email Service (optional)

To send campaigns from the collected emails:

  1. Install MC4WP: Mailchimp for WordPress (or ConvertKit plugin).
  2. Copy its shortcode, e.g. [mc4wp_form id="1"].
  3. Paste it in Customize -> Newsletter Settings -> Plugin Shortcode — this replaces the built-in form.

Alternatively, fill Form Action URL with your ESP endpoint to override the built-in storage.

11. FAQ

Where do I edit the About page content?

Create/edit a page, fill in the title, excerpt, featured image, and body content in the editor, then select the About template.

Does the theme work with the Classic Editor?

Yes. All content is rendered through the_content(), so both Gutenberg and Classic Editor work.

Why is my homepage blank?

Check Settings -> Reading: it must be set to "Your latest posts" (not a static page).

How do I remove the demo content?

Go to Appearance -> Import Demo and click Remove Demo Content.

Can I change the accent color?

Yes — Appearance -> Customize -> Colors -> Accent (Neon).
